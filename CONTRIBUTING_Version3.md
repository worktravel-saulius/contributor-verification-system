# Contributing to the Contributor Verification System

Thanks for contributing to WorkTravel Academy.

## Contribution Rules

All contributions should be:
- relevant to project verification and governance
- clearly documented
- peer-review friendly
- aligned with real contributor workflows

## Valid Contribution Types

The following are eligible for verification:
- merged feature PRs
- bug fixes
- docs improvements
- tutorials
- course module improvements
- review feedback that adds value

## Review Framework

When submitting work:
- include a summary of the change
- explain why it matters
- identify the relevant verification flow
- attach or reference tests if applicable

## Code Quality Expectations

- keep changes focused
- avoid unrelated scope
- write clear commit messages
- follow repository conventions
- keep documentation up to date

## Credit Mapping

- +500 Credits: merged stacked feature PR
- +300 Credits: bug bounty or UX fix
- +250 Credits: docs/tutorial improvements
- +150 Credits: peer review contribution

## PR Process

1. open a PR
2. complete a clear description
3. request review
4. make updates if necessary
5. merge after approval

## Questions

For questions, open a discussion or contact the project maintainers.
