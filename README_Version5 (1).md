# Contributor Verification System

This repository defines the verification framework for WorkTravel Academy contributions.

## Purpose

This system records and validates contributor work so that credits can be awarded based on:
- merged pull requests
- quality of implementation
- peer review
- documentation contributions
- bug fix work
- project completion and governance compliance

## Credit Flow

A contribution is considered eligible when:
1. the PR is merged
2. automated checks pass
3. governance rules are respected
4. the submission matches an approved contribution type
5. the proof-of-work is recorded

## Credit Categories

- +500 Credits: Merged feature or stack PR
- +300 Credits: UX or bug bounty fix
- +250 Credits: Documentation or tutorial contribution
- +200 Credits: Course module completion
- +150 Credits: Peer code review

## Governance Rules

Contributors should:
- open clear PRs
- include tests where applicable
- document relevant changes
- adhere to repository standards
- keep review threads constructive
- avoid low-quality or low-scope work

## Quick Start

1. Fork the relevant repository
2. Create a feature branch
3. Submit a PR with clear scope
4. Ensure CI checks pass
5. Request review
6. Merge after approval
7. Credits are recorded through the verification workflow
