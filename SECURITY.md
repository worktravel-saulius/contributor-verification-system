# Security Policy

## Reporting a vulnerability

Do **not** open a public issue for a suspected security issue involving the WorkTravel Academy bonus system, member data, credentials, automation routes, or reward logic.

Send a concise private report to **UK@worktravel.agency** with:

- affected repository, route, or workflow;
- reproducible steps using synthetic data only;
- the impact; and
- any safe mitigation already identified.

Do not include passwords, access tokens, webhook query values, customer/member records, or raw production payloads.

## Scope

This policy covers the `contributor-verification-system` documentation and any future GitHub-to-bonus integration. The currently active Wix and Cloud Run bonus surfaces are operated separately and must not be changed through a public issue.

## Disclosure

Please allow the operating owner reasonable time to confirm and remediate a report before sharing details publicly.
